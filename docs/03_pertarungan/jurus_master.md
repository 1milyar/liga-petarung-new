# MASTER DATA JURUS & TEKNIK

## DAFTAR JURUS EPISODE 1 & 2

### 1. Geser Sumbu (`jurus_geser_sumbu`)
- **Tipe**: Hindar
- **Biaya Qi**: 0
- **Tag Kuat**: CEPAT
- **Tag Lemah**: Serangan Menyapu (BERAT)
- **Penguasaan**: Mentah -> Terlatih -> Mahir
- **Deskripsi**: Melangkah samping 45 derajat memindahkan poros tubuh dari garis serangan lawan.

### 2. Siku Penangkis (`jurus_siku_tangkis`)
- **Tipe**: Tangkis
- **Biaya Qi**: 10
- **Tag Kuat**: Pukulan Lurus / Hook (CEPAT)
- **Tag Lemah**: Serangan BERAT (Menguras Stamina jika dipaksa)
- **Penguasaan**: Mentah -> Terlatih -> Mahir
- **Deskripsi**: Menggunakan tulang siku keras untuk menangkis dan membelokkan arah pukulan.

### 3. Tapak Terbuka (`jurus_tapak_terbuka`)
- **Tipe**: Serang
- **Biaya Qi**: 15
- **Tag Kuat**: BERTAHAN (Pecah Postur)
- **Tag Lemah**: CEPAT
- **Penguasaan**: Mentah -> Terlatih -> Mahir
- **Deskripsi**: Dorongan telapak tangan bermuatan gelombang energi internal untuk merusak keseimbangan.

### 4. Napas Dalam (`jurus_napas_dalam`)
- **Tipe**: Napas / Utility
- **Biaya Qi**: -25 (Memulihkan Qi)
- **Tag Kuat**: Membuka petunjuk kelemahan (*Tell*)
- **Tag Lemah**: Memberi 1 giliran gratis pada musuh jika salah waktu
- **Penguasaan**: Mentah -> Terlatih -> Mahir
- **Deskripsi**: Menarik napas diafragma dalam untuk menenangkan sirkulasi darah dan fokus pikiran.

### 5. Tangkapan & Kunci Leher (`jurus_kunci_leher`)
- **Tipe**: Banting / Finisher
- **Biaya Qi**: 30
- **Syarat**: Hanya bisa dieksekusi saat Celah Emas terbuka atau lawan terlanjur menerjang.
- **Penguasaan**: Mentah -> Terlatih -> Mahir
- **Deskripsi**: Mengunci leher dan persendian lawan menggunakan berat tubuh untuk lemparan KO.
